# BYOK LLM Providers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the Gemini-specific post-mortem integration with configurable BYOK support for supported providers and discovered models.

**Architecture:** Store a provider-agnostic LLM profile in encrypted configuration. A backend provider adapter selects provider-specific authentication, request, and model-discovery endpoints and normalizes generated text to the existing `{analysis}` contract. The renderer selects only supported presets and discovers models without changing Journal callers.

**Tech Stack:** Python standard-library HTTP client, SQLite-backed trade journal, Electron IPC, React/TypeScript, pytest, Ruff.

**Spec:** GitHub issue #49.

## Global Constraints

- API keys must remain encrypted at rest and must never be logged or returned in plaintext.
- Provider failures must not affect scanning or trading.
- Tests must be offline and must not call provider APIs.
- Gemini remains supported through its native API and `gemini-2.5-flash` default.
- Supported providers are OpenAI, Anthropic, Gemini, OpenRouter, Ollama, and OpenCode; Bedrock and arbitrary custom endpoints are deferred.
